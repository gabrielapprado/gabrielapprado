## 💻 Gabriela Prado

### Estudante de Desenvolvimento de Software Multiplataforma na FATEC

Tenho uma base sólida em lógica de programação e gosto de transformar problemas em soluções simples e funcionais. Trabalho com Python, JavaScript, TypeScript e Node.js, aplico conceitos de Programação Orientada a Objetos e desenvolvo interfaces com HTML, CSS e Bootstrap. Também tenho conhecimentos em SQL para manipulação de dados, e uso Git e GitHub para versionar meu código com boas práticas.

Estou em busca da minha primeira oportunidade de estágio em tecnologia, com vontade genuína de aprender, contribuir em equipe e evoluir como desenvolvedora a cada novo desafio.
